# UI-design-with-sigma

**About the Project**

Study Plans is a student-focused website UI design created using Figma. It helps students organize their studies, manage learning resources, and plan their academic goals.

**Features**

- Welcome page
- Login and sign-up screens
- AI study chatbot
- Study planner
- Study plan management
- Learning resources

**Tools Used**

- Figma – UI/UX Design
- GitHub – Project Hosting

**Project Purpose**

This project was created to practice UI/UX design and develop a simple, user-friendly study planning experience for students.

**Future Improvements**

- Add reminders and notifications
- Add progress tracking
- Improve mobile responsiveness
- Develop a functional website
